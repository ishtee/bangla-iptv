# Bangla IPTV

Auto-updated M3U playlist and EPG of Bangladeshi TV channels, built from the [iptv-org](https://github.com/iptv-org/iptv) database. Dead streams are removed daily.

## Usage

Add this URL as a playlist in any IPTV player:

https://raw.githubusercontent.com/ishtee/bangla-iptv/main/bangla-iptv.m3u

EPG (placeholder guide):

https://raw.githubusercontent.com/ishtee/bangla-iptv/main/epg.xml

## How it works

Runs every day, checks each stream, and commits the updated files.

## Disclaimer

This repo only links to publicly available streams and does not host any video content. Stream availability depends on the channel owners.
